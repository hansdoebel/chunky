# Pre-embedded dataset compatibility

The curated profile supports [Qdrant's DBpedia OpenAI small 1536 dataset](https://huggingface.co/datasets/Qdrant/dbpedia-entities-openai3-text-embedding-3-small-1536-100K) at revision `0d5fd00fbc5a9c0c836d70cd409f7e461255e572`, configuration `default`, split `train`. The source declares `text-embedding-3-small` and the exact `text-embedding-3-small-1536-embedding` column. Its separate `openai` column contains different, older vectors with the same dimensions and is never substituted. The complete `combined_text` and `_id` are retained; precomputed vectors are not regenerated or paired with newly split text.

Use an OpenAI-compatible query gateway configured for exactly `text-embedding-3-small` with 1536 dimensions. The gateway must return that exact model identity in its response as well as a finite, nonzero 1536-dimensional vector. Missing identity, aliases, other models, other revisions and matching dimensions alone do not establish compatibility. This preserves the existing gateway configuration; Chunky does not add authentication, download a replacement encoder or change saved providers automatically. No live OpenAI inference was performed during fixture validation.

Cloud ingestion registers the new collection's verified profile only after creation and configuration verification. Subsequent local-route queries use the same strict response check. Local Mac query routing can connect to the remote Cloud database; worker query routing is refused for these registered collections because that path cannot provide this strict gateway verification. Ordinary document ingestion cannot append into a registered pre-embedded collection. Existing unrelated Ollama, OpenAI-compatible and CPU collections retain their behavior.

The source card does not declare a license; review the source terms before use. Live metadata checked on 2026-11-17 reports 100,000 rows and 1,650,651,517 compressed Parquet bytes. JSONL samples contain both original vector columns and can be larger. Neither download size nor vector dimension predicts Cloud storage usage: the separate Cloud import preflight accounts for vectors, payloads, indexing and remaining per-node capacity. Collection quotas are delayed safeguards, not a guarantee against every storage overhead or concurrent writer.

This profile is the compatibility foundation for the Cloud import workflow in [PER-228](https://linear.app/hansdoebel/issue/PER-228). It does not restore external snapshots or mutate an existing collection.
